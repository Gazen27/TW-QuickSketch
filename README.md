## Getting started
### Prerequisites
**Node.js** and **npm** are required.
### Installation
1. Install dependencies *(both in backend and frontend)*
```
npm install
```
### Executing
2. Starting local server *(in backend)*
```
npm run dev
```
3. Starting Angular frontend *(in frontend)*
```
ng serve
```
4. Open http://localhost:4200 in your browser
