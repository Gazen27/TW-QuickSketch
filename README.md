## Getting started
### Prerequisites
**Node.js** and **npm** are required.
### Installation
1. Install dependencies
```
npm install
```
### Executing
2. Starting local server (in backend)
```
npm run dev
```
4. Starting Angular frontend
```
cd ..\frontend\
ng serve
```
5. Open http://localhost:4200 in your browser
