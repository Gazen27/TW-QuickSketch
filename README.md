## Getting started
### Prerequisites
**Node.js** and **npm** are required.
### Installation
1. Install backend dependencies\
Navigate to ../backend
```
npm install
```
2. Install frontend dependencies
```
In ../frontend/
npm install
```
### Executing
3. Starting the local server
```
In ../backend/
npm run dev
```
4. Starting Angular frontend
```
In ../frontend/
ng serve
```
5. Open http://localhost:4200 in your browser
